ZIP FOR_PROFESSOR AND SEND IT
=============================

When the dual-branch + Stage-4 run finishes, do this in File Explorer:

  1. Open:
       AICTFProject\6v6\

  2. Right-click the folder:
       FOR_PROFESSOR

  3. Choose:
       Compress to ZIP file
       (or Send to > Compressed (zipped) folder)

  4. Send that ZIP (email / Drive / USB).

No PowerShell. No rebuild script. Do not open the artifacts tree.

Inside FOR_PROFESSOR, open START_HERE.txt then SUMMARY\SUMMARY.txt.

Rule: if it is not inside FOR_PROFESSOR/, the professor does not need it.

While the run is still going, watch:
  dual_branch_OVERALL.log.err
FOR_PROFESSOR/ appears only when the pipeline finishes (READY_TO_ZIP.txt inside).
