# 6v6 handoff folder

**This is the single folder to send.** Everything the school-PC pipeline produces for 6v6 is copied here as stages finish.

No paper charts are generated by training. This folder holds **models + sealed results + logs**.

---

## For the professor (send this)

After the run finishes (or at any checkpoint), from `AICTFProject`:

```powershell
powershell -ExecutionPolicy Bypass -File experiments/pack_6v6_handoff.ps1
```

That writes `6v6/6v6_handoff_<date>.zip`. Email / Drive / USB that zip.

Or zip manually:

```powershell
Compress-Archive -Path .\6v6\* -DestinationPath .\6v6\6v6_handoff.zip -Force
```

```text

  MANIFEST.json             <- what exists, hashes, paths (updated as stages complete)
```

Canonical training trees still also live under `artifacts/scale_6v6_specialists/…` (metrics CSVs, periodic ckpts). This folder is the **portable subset** for sharing.
